## What I Do

I focus on **data platform and backend engineering** — building the systems that move, validate, transform, store, and serve data reliably at scale.

My interests sit at the intersection of:

| **Data Pipelines** | **Data Platforms** | **Backend Systems** |
|:---:|:---:|:---:|
| Batch & event-driven processing | Analytical & relational storage | APIs & service layers |
| Ingestion & normalization | Data quality & reliability | Distributed workflows |
| Orchestration & backfills | Data serving & access | Infrastructure tooling |

---

## Engineering Focus

### Data Pipelines

`Sources → Ingestion → Validation → Storage → Processing`

I build pipelines around reliability rather than just data movement:

- Batch and event-driven ingestion
- Resumable backfills and checkpointing
- Idempotent processing and replay safety
- Data validation and reconciliation
- Cross-source normalization
- Rate-limited and concurrent processing
- Durable retry and failure recovery
- Workflow orchestration

---

### Data Platforms

`Raw Data → Trusted Storage → Query & Delivery`

I work on systems that make heterogeneous data usable and accessible downstream:

- Relational and analytical data modeling
- High-volume time-series storage
- PostgreSQL and ClickHouse architectures
- Parquet-based data interchange
- Query and serving layers
- Python data tooling and SDKs
- Polars and PySpark workflows
- Data contracts and canonical representations

---

### Backend & Distributed Systems

`Data → Services → APIs → Clients`

I also build the backend infrastructure surrounding data platforms:

- Java / Spring Boot services
- Python backend tooling
- REST API design
- PostgreSQL-backed applications
- Kafka-based event processing
- Containerized services with Docker
- Database migrations with Liquibase
- Reliability and failure handling
- Distributed systems concepts and Go

---

### ML Infrastructure

`Trusted Data → Processing → Models → Outputs`

My longer-term focus is applying a strong data-platform foundation to machine learning systems:

- ML-ready data pipelines
- Dataset preprocessing and normalization
- Model input/output infrastructure
- Batch and event-driven inference workflows
- Model evaluation pipelines
- Local model serving and experimentation
